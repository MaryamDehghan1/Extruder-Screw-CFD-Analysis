# Extruder-Screw-CFD-Analysis
CFD analysis of material flow, pressure, temperature, and velocity distribution in an extruder screw using ANSYS Fluent.
CFD Analysis of Material Flow in an Extruder Screw

Project Overview

This project presents a computational fluid dynamics (CFD) study of material flow in an extruder screw using ANSYS Fluent. The analysis focuses on the distribution of pressure, temperature, and velocity within the modeled extrusion domain.

The repository contains selected simulation figures and post-processing results. The complete simulation model and project files are not included.

Numerical Model

- Software: ANSYS Fluent
- Geometry: Extruder screw and surrounding flow domain
- Fluid model: Power-law viscosity model
- Density: 1170 kg/m³
- Screw rotational speed: 30 rpm
- Inlet normal velocity: 0.01 m/s
- Outlet condition: Outflow
- Barrel wall condition: Zero wall velocity

The material properties, boundary conditions, and numerical assumptions should be interpreted in the context of the modeled case. Additional solver details and material parameters can be provided where available.

Results

The following figures present selected outputs from the simulation:

- Geometry and mesh: Overview of the screw geometry and computational mesh.
- Temperature distribution: Spatial variation of temperature in the modeled domain.
- Pressure distribution: Pressure field obtained from the CFD analysis.
- Axial velocity distribution: Distribution of the velocity component along the specified coordinate axis.
- Reference comparison: Comparison of selected flow-rate and pressure results with a published reference study, where applicable.

Limitations

This repository presents selected numerical results rather than a complete, independently reproducible simulation package. The results should be interpreted with consideration of the modeling assumptions, mesh characteristics, boundary conditions, and available validation evidence.
